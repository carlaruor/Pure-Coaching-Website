# Contributing to the Pure Coaching website

## Project language

English is the only project language. Use clear Australian English for all user-facing content, including page copy, forms, labels, buttons, validation messages, notifications and email templates.

Use English for code identifiers, component and configuration names, comments, documentation, placeholders, example values, test descriptions and deployment instructions. New public configuration placeholders should follow an explicit English pattern such as `YOUR_PUBLIC_TURNSTILE_SITE_KEY`.

Do not translate or rename an existing identifier when doing so could break an API contract, stored payload, database column, HTML/JavaScript integration or other compatibility-sensitive behaviour. In those cases, preserve the identifier and document its purpose in English.

Never replace, translate or commit real API keys, secrets or credentials. Keep user-facing terminology professional, accessible and consistent with the Pure Coaching design and privacy requirements.
